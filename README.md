# Arup Biswas — personal website

Personal website of Arup Biswas (non-equilibrium statistical physics, Harvard University).

A single static page (`index.html`) with live in-browser simulations on every section:
active Brownian particles, the Lorenz attractor, diffusion with stochastic resetting
(with an interactive playground), diffusive spreading, a Galton board, the 2D Ising model,
Vicsek flocking and Langevin dynamics in a double well.

No build step: GitHub Pages serves the files as they are.
